DADOS + ORGANIZAÇÃO = ESTRUTURA

Uma estrutura de dados é uma forma de organizar e representar dados de maneira que determinadas operações possam ser realizadas sobre eles.

O que foi feito com o caso das notas?

1- Identificação dos dados
2- Organização dos dados

Depois disso podemos saber:

1. Como acessar?
2. Como buscar?
3. Como inserir?
4. Como remover?
